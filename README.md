# Свинина Талины на Филиппины: калькулятор

**Открыть:** https://daniilglushko.github.io/pork-ph-direct/

Калькулятор показывает, сколько тонн в год нужно поставить через свою компанию в Маниле, чтобы получить нужную чистую прибыль. Ползунками задаются цель, цена завода, цена продажи в Маниле, пошлина и расходы в порту; разбор одного килограмма, график и таблица пересчитываются сразу. Настройки сохраняются в ссылке.

Вся логика — в `index.html`, без сборки.
