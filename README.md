# Свинина Талины на Филиппины без посредников: сколько можно заработать

**Открыть страницу:** https://daniilglushko.github.io/pork-ph-direct/

Расчёт на 5 ноября 2026 года. Сколько тонн в год нужно продать через свою компанию в Маниле и сколько чистой прибыли это даст. Считаем по фактическим отгрузкам МПК Атяшевский в 2026 году, прайсу Талины от 16.10.2026 и оптовым ценам Манилы.

- `calc.py` — расчёт, все допущения в начале файла.
- `build.py` — собирает `index.html` из расчёта.

```bash
python3 build.py
```
